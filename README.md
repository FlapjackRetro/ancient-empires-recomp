# Ancient Empires — static recompilation

A static recompilation of the 1991 DOS game *Ancient Empires*
(`AEPROG.EXE`) into portable C, with a small PC/DOS/VGA runtime and an SDL2
front end, so it builds and runs natively on **Windows** (and Linux/macOS)
without DOSBox.

The game's code is not rewritten: every function in the original 16-bit
executable was lifted instruction by instruction into C, and the machine it
expected (DOS services, BIOS, VGA, PIT timer, PC speaker, keyboard) is
provided by the runtime in `src/recomp/`.

> **You need your own copy of the game.** This repository contains no game
> data and no original code. Copy `AEPROG.EXE`, `AE000.DAT`, `AE001.DAT`
> from your copy of Ancient Empires next to the program, or point at them with
> `--game-dir`. *Ancient Empires* is © 1990–1991 The Learning Company.

## Build (Windows, Visual Studio + vcpkg)

```
vcpkg install sdl2:x64-windows
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=%VCPKG_ROOT%/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
build\Release\empires.exe --game-dir C:\path\to\AncientEmpires
```

Linux / macOS: install SDL2 development files, then
`cmake -S . -B build && cmake --build build -j && build/empires --game-dir ~/ae`.

## Run

```
empires [--game-dir <dir>] [--scale <n>] [--fullscreen] [--adapter vga|ega|tandy|cga]
```

`F11` toggles fullscreen. Player data is read and written in the game directory by the original code, unchanged.

Testing options: `--headless`, `--max-seconds`, `--frame-dir`, `--frame-every`,
`--keys "9=ENTER,12=SHOT"`, `--trace`.

## How it works

| Piece | Where |
|---|---|
| Function discovery | `tools/analyze_empires.py` (pcrecomp) + Ghidra's procedure list (`work/ghidra_functions.json`) + indirect-call targets found by running the game (`work/misses.txt`) |
| Lifter driver | `tools/lift_empires.py` — decodes, finds jump tables, lifts every function with pcrecomp's `lift16`, writes `src/recomp/gen/*.c` |
| Generated code | `src/recomp/gen/` (≈460 functions) — regenerated by the tool; checked in so the project builds without Python |
| CPU/memory model | `src/recomp/cpu.[ch]` (from pcrecomp) |
| DOS / BIOS / PIT / keyboard | `src/recomp/runtime.c` |
| EGA/VGA (planar, latches, write modes 0–3, DAC, CRTC, mode 13h/0Dh/0Eh/text) | `src/recomp/vga.c` |
| Window, input, audio output (PC speaker square wave + OPL2 mixed) | `src/platform_sdl.c` |
| AdLib / Sound Blaster FM (YM3812) on ports 0x388/0x389 | `src/opl.cpp` wrapping [ymfm](https://github.com/aaronsgiles/ymfm) (BSD-3, `third_party/ymfm/`) |

Two things about this particular game worth knowing:

* **The graphics driver is loaded at run time.** `AEPROG.EXE` reserves
  `cs:039C–0AFA` and the game decompresses a driver into it from `AE000.DAT`.
  Static recompilation can't see code that doesn't exist yet, so the loaded
  driver was captured from a running game (`work/overlay_vga.bin`) and lifted as a
  second code set; calls into that range go through `ovl_call()`, which checks
  that the driver in memory is the one that was lifted. VGA and EGA load the same
  driver. CGA/Tandy/Hercules code paths are not covered.
* Return addresses on the guest stack are placeholders, because lifted functions
  return with C `return`. The one place the C startup code reads its own return
  address (`jmp cs:[0xE656]`) is patched in `tools/lift_empires.py`.

### Audio

The game detects an AdLib card by timing the YM3812's timers, then plays music
through it; otherwise it falls back to the PC speaker. Both are emulated and mixed:
the speaker from port 0x61 + PIT channel 2, the FM chip with ymfm. The chip timers
run on wall-clock time plus a small per-port-access bonus, because the recompiled
code reaches the timer-detection loop far faster than a real 286 would and would
otherwise conclude there is no card. `--wav out.wav` captures the mixed audio
without a sound device (handy for headless testing).

### Regenerating the C

```
PCRECOMP_HOME=/path/to/pcrecomp python3 -I tools/lift_empires.py
tools/iterate.sh /path/to/game   # merge dispatch misses -> relift -> rebuild -> smoke run
```

`pcrecomp` (https://github.com/sp00nznet/pcrecomp, MIT) supplies the x86-16
decoder, lifter and CPU runtime this project is built on.

## Status

Boots, shows the title/intro, plays AdLib music, reads the player list, accepts keyboard input,
runs the sign-in flow. Gameplay coverage is being widened; please report
screens that look wrong.
